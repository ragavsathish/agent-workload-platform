Material Icons subset: generated by Flutter 3.47.7 for the Pi Voice web build from its bundled MaterialIcons-Regular font. The shared CSS uses the same codepoints as the corresponding Flutter `Icons.*` constants so React and Flutter headers render the same glyph family. The subset is 11 KB; rebuild the Flutter web client after adding a glyph, then update this file if the icon subset changes.
