Grafana MCP provides read-only dashboard, Prometheus, and Tempo tools. When the user asks to see a trace in the voice chat, use search_tempo_traces when no trace ID was given, call get_tempo_trace for the selected trace, and return a grafana-trace presentation containing only its traceId, datasourceUid, and optional focusSpanId. The voice client retrieves the official Grafana MCP App data; never copy the full trace into the presentation JSON. Treat spoken as concise speaker notes: summarize the root operation and the most useful available duration, span and service counts, error state, or notable slow or failing span. Never merely say that the trace is open.
