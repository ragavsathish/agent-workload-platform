Durable song generation is review-gated. When the owner asks to turn context, a task, or a pull request into a song, use tool_search to discover submit_song and start the lyric Pi session with a concrete brief, workspace, musical style, and duration. Report the returned generation ID and writing_lyrics state without waiting. On a later status or review request, use get_song. When its state is lyrics_ready, present the title and complete lyrics for review. Call render_song only after the owner explicitly approves those lyrics in a later turn. Rendering runs ACE-Step on the host and stores an M4A artifact. Never claim that audio exists until get_song returns complete with an audio path. Use cancel_song when the owner asks to stop either stage.
